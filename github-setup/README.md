# GitHub初期設定スクリプト (`github.sh`)

このスクリプトは、WSL2環境でGitの基本情報（ユーザー名・メールアドレス）を登録し、GitHubと安全に通信するためのSSHキー（ed25519方式）を自動生成する一発設定スクリプトです。

パスワードやアクセストークンをファイル内に直接書き込まない、安全な設計になっています。

## 🛠 処理内容

1. **Gitグローバル設定の登録:** `user.name` と `user.email` をシステムに登録します。
2. **SSH鍵の自動生成:** 現在最も安全とされる `ed25519` 方式で公開鍵・秘密鍵を作成します。
3. **登録用キーの表示:** 実行の最後に、GitHubにコピペするだけの公開鍵文字列を画面に出力します。

## 🚀 使い方

### 1. 実行権限の付与
スクリプトをダウンロードした場所で、以下のコマンドを実行して実行権限を与えます。
```bash
chmod +x github.sh
```

### 2. スクリプトの実行
```bash
./github.sh
```

### 3. 対話形式での入力

1. ターミナルの指示に従って、GitHubの ユーザー名 と メールアドレス を入力します。
2. 鍵の生成が始まり、「（すべてEnterを押してください）...」と表示されたら、パスフレーズを空にするために何も入力せずEnterキーを3回押してください。

## 🔑 実行後の必須作業（GitHubへの登録）

スクリプトの実行が完了すると、ターミナル画面に `ssh-ed25519 AAAAC3...` から始まる長い文字列（公開鍵）が表示されます。

1. 画面に表示された `ssh-ed25519 ...` の文字列を、最初の文字から最後のメールアドレスまで残さずすべてコピーします。
2. ブラウザで [GitHubのSSHキー設定ページ](https://github.com/settings/keys) を開きます。
3. 右上の **「New SSH key」** ボタンをクリックします。
4. 以下の通りに入力して登録します。
   * **Title:** 自由な名前（例: `wsl2-ubuntu`）
   * **Key type:** `Authentication Key` (デフォルトのまま)
   * **Key:** ターミナルからコピーした文字列をそのまま貼り付け
5. **「Add SSH key」** をクリックして保存すれば完了です。

次回以降、リポジトリを扱う（`git clone` や `git push` など）際は、**HTTPSのURLではなく「SSHのURL」を使用する**ことで、パスワード入力なしで安全に通信できるようになります。
