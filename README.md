# unix-setting-script

WSL2（Ubuntuなど）の開発環境構築、プロキシ切り替え、GitHub関連の設定を自動化・効率化するためのシェルスクリプト集です。
環境構築のたびに発生する手動の手間を減らし、快適なLinux環境を素早くセットアップすることを目的としています。

## 🛠 機能一覧

このリポジトリは機能ごとにフォルダが分かれており、各フォルダ内に専用の説明書（README）を同梱しています。必要な機能を選んでセットアップしてください。

### 1. [GitHub初期設定](./github-setup/)
*   **フォルダ:** `github-setup/`
*   **概要:** Gitのユーザー情報（ユーザー名・メールアドレス）の登録や、安全な通信のためのSSHキー（ed25519）の自動生成を行います。

### 2. [プロキシ自動設定](./proxy-auto-settings/)
*   **フォルダ:** `proxy-auto-settings/`
*   **概要:** ターミナル起動時にネットワーク環境等に応じてプロキシ環境変数を自動で適用・管理するためのスクリプト群です。

## 🚀 使い方（クイックスタート）

1. 各フォルダの説明書（README）を参照し、自分が必要なスクリプトファイルをそれぞれダウンロードしてください。

2. スクリプトを実行する前に、ターミナルで以下のコマンドを実行して実行権限を付与することをお勧めします。
   ```bash
   chmod +x "ダウンロードしたスクリプト名.sh"
   ```
